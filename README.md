# منبّه الدواء / Medikamenten-Alarm / Medicine Alarm (Android)

المرحلة 1: جدول أدوية كامل + منبّه يرنّ على قناة المنبّه (فوق الصامت) ولا يتوقف إلا بزر «أخذته».
Phase 1: full dose schedule + alarm on the ALARM stream that rings until "Taken".

## البناء على GitHub
1. ارفع محتويات هذا المجلد إلى مستودع جديد (فرع main).
2. تبويب Actions ← Build APK ← انتظر النجاح ← نزّل الملف من Artifacts (medicine-alarm-apk).
3. فكّ الضغط وثبّت ملف app-debug.apk (اسمح بالتثبيت من مصدر غير معروف).
4. عند أول تشغيل امنح كل الأذونات المطلوبة: لا يعمل الجدول قبلها.

## اختبار إلزامي قبل الاعتماد عليه
زر «جرّب المنبّه»: اقفل الشاشة، ضع الهاتف على الصامت ثم على «عدم الإزعاج»، ثم وضع توفير البطارية، وتأكد أنه يرنّ في كل حالة.
بعض الأجهزة (Xiaomi, Huawei, Oppo, Samsung) تقتل التطبيقات في الخلفية: فعّل «التشغيل التلقائي» وأزل قيود البطارية من إعدادات الهاتف.

## غير موجود بعد
الربط بأجهزة أخرى، وإرسال «لا يجيب على المنبّه» (المرحلة 2)، وآيفون (المرحلة 3).
