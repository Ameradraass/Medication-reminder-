# 💊 مُذكّر الدواء (PWA)

تطبيق ويب يُثبَّت على الهاتف كتطبيق، ويعمل بدون خادم خاص.

## المزايا
- اسم الدواء + عدة أوقات يوميًا (ساعة) + اختيار الأشهر.
- صوت منبّه مختلف لكل دواء (5 أصوات + تجربة الصوت) + اهتزاز + إشعار.
- أزرار: أخذتُ الدواء / تأجيل 10 دقائق / تخطّي. وبعد 30 دقيقة دون تأكيد تُسجَّل الجرعة "فائتة".
- ربط بهاتف آخر (مرافق): يصله إشعار عند أخذ الدواء أو نسيانه أو قرب نفاد العلبة.
- تنبيه "اشترِ علبة جديدة" عندما يتبقى دواء يكفي يومين أو أقل.
- يعمل بدون إنترنت (عدا الربط).

## 1) رفعه إلى GitHub وتشغيله
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (بعد فك الضغط).
2. من Settings ← Pages ← Source: `Deploy from a branch` ← الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط الناتج على الهاتف، ثم من المتصفح اختر "إضافة إلى الشاشة الرئيسية".

## 2) تفعيل الربط مع هاتف آخر (Firebase مجاني)
1. أنشئ مشروعًا في https://console.firebase.google.com
2. Build ← Firestore Database ← Create database.
3. Project settings ← Your apps ← إضافة تطبيق ويب `</>` وانسخ الإعدادات إلى `firebase-config.js`.
4. Firestore ← Rules: الصق محتوى `firestore.rules` ثم Publish.
5. هاتف المريض: تبويب "الربط" ← "أنا المريض" ← سيظهر رمز. هاتف المرافق: "أنا المرافق" وأدخل الرمز.

## ⚠️ حدود مهمة
- المنبّه في تطبيقات الويب يعمل بشكل موثوق **والتطبيق مفتوح** (أو الشاشة مضاءة). المتصفحات تمنع الصوت والتوقيت الدقيق في الخلفية.
- للحصول على منبّه حقيقي في الخلفية وإشعارات push للمرافق وهو مغلق التطبيق، حوّله لاحقًا إلى تطبيق أندرويد/آيفون عبر **Capacitor** (يستخدم نفس الكود) مع إشعارات محلية وFirebase Cloud Messaging.
- هذا التطبيق تذكيري فقط وليس بديلًا عن نصيحة الطبيب أو الصيدلي.
